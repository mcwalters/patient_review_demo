The model decides what to ask each specialist, whether a gap is real given the whole regimen, whether an unreturned test still matters, whether a rate is clinically credible, and what to raise first in what words. It never touches the database, computes a number, decides whether a finding is recorded, or chooses which specialists run — the answer was always all three, and they are consulted concurrently.

Two things run outside the review. The audit judges the extract before any patient logic executes — it is a real agent making real model calls. The priority score is not: a model wrote its weights once, offline, into a JSON file a clinician edits, and every run since is code reading a static file. That is why it is drawn dashed rather than blue. No model scores a patient, so the same panel produces the same numbers every time.

What the code guarantees, not the model. Nine findings are computed before any agent runs and the review refuses to start without them. A finding naming a patient who is not on the roster is refused; one whose evidence discusses somebody it does not list is flagged. Any high‑severity finding the report fails to cite is raised above it. None of those depends on the model cooperating.

The caveat to volunteer: the three-specialist split is the part I cannot justify on measurement. A/B‑tested twice against a single agent holding the same tools: the first battery gave the single agent a large latency advantage, which disappeared once the specialists were consulted concurrently, and the re‑run came out even — 133s against 136s over six runs an arm. What survives is that the supervisor spends about 2.2× the model calls for comparable output, and the single agent’s patient set is more reproducible. The shape came from specific hand‑off failures, not from a comparison.

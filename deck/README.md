# The slides

Four slides on reasoning, not a walkthrough of the prototype. Published as a
Claude artifact; this is the source, kept in the repo so the claims on the
slides can be diffed against the code that backs them.

| file | slide |
|---|---|
| `slides/problem.html` | Who this helps, and why attention is the scarce resource |
| `slides/data.html` | Four findings in the data that changed the design |
| `slides/controls.html` | Six ways this could be wrong, and the control for each |
| `slides/safety.html` | Where the model is allowed to reason, and what the floor bought |

`assets/architecture.html` is not a slide. It is a standalone page to open in
a browser tab if anyone asks how the agents relate -- eight model agents, the
deterministic layer under them, and the counts from a real cached run. Four
slides was the brief, and an architecture walkthrough is a Q&A answer rather
than a thing to spend presenting time on.

`deck.json` sets the order. Each slide carries its speaker notes in its
`<aside>`, which is where the caveats live -- what a number does not prove,
what to say if someone pushes, and which claims are assumptions.

## Every figure on a slide comes from somewhere

The numbers are not illustrative. They are regenerated by:

    ./.venv/bin/python -m pytest tests/ -q        # 57 tests
    ./.venv/bin/python evals/stability.py 5       # ~25 min, ~$1.40
    ./.venv/bin/python -m prototype.preflight     # the data audit
    ./.venv/bin/python -m prototype.score         # the priority score

If a slide and the repo disagree, the repo is right and the slide is stale.

## One claim on the slides is not from this repo

Slide 1 says trained reviewers clear "six to twenty" charts a day. That is the
2025 CDI Week Industry Survey, reported in the ACDIS Q&A on Productivity:
6-10 new reviews per day for 59.78% of respondents, 11-15 for 18.95%, and one
specialist's team at a daily average of 20 including re-reviews.

It is inpatient clinical documentation integrity -- a different role and
setting from population-health panel work, which carries outreach the CDI
number does not measure. It is cited as evidence that reading is fast, which is
the argument, not as a throughput target for this user. The speaker notes say
to give that caveat before being asked.

An earlier draft claimed a nurse reviews "about fifteen a week". That was an
assumption with no source behind it, and the argument turned out to be stronger
without it: if reading is cheap, the bottleneck is what a finding costs after
you read it, which is the case for a ranked worklist rather than a longer list.
